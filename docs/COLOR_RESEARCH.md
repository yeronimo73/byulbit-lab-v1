# 별빛연구소 색채·빛 집필 가이드

**문서 유형**: 내부 집필·검수 기준 (공개 페이지 아님)  
**일자**: 2026-06-07  
**적용 범위**: `signs.json`, `planet-types.json`, `color-atlas.json`, `research-notes/`, 인포 `light` 층, UI 카피  
**정본 참고문헌**: `data/research-bibliography.json`

---

## 1. 목적

별빛연구소의 「빛 · 색채」 축은 **점술·치료·성격 단정을 색으로 포장하지 않는** 선에서 씁니다.  
이 문서는 집필자(Elon/Cup)와 검수자(Coco/Rostar)가 같은 기준으로 카피를 쓰고 고르기 위한 내부 가이드입니다.

**한 줄 원칙**: 연상 ≠ 체감. 천문색 ≠ 디자인 hue. 거울 ≠ 판결.

---

## 2. 세 층 분리 (필수)

모든 색 관련 카피는 아래 층을 **문단·필드 단위로 분리**합니다. 한 문장에 섞지 않습니다.

| 층 | 무엇인가 | 어디에 쓰나 | 금지 |
|----|----------|-------------|------|
| **천문 · 빛** | 검증 가능한 사실 (스펙트럼, 반사, 위상, 표면 성분) | `astronomyFacts`, `skyColorFact`, 연구 노트 facts | 운세·출생·성격과 연결 |
| **디자인 hue** | UI·가독성·원소 상징용 hex | `color`, `color-atlas.json`, `hueNote`, `lightNote` 일부 | 「천체의 진짜 색」 단정 |
| **심리 거울** | 그날의 연상·질문·10초 실습 | `colorAssociation`, `colorPractice`, `mirror` 층 | MBTI/별자리/치료 효과 단정 |

**좋은 예 (쌍둥이자리)**  
- 천문: 폴룩스는 오렌지빛 거성, 카스토르는 상대적으로 푸른 빛.  
- 디자인: `#6ec8c8`은 공기·대화 상징색.  
- 거울: 「이 hue가 떠올리게 하는 단어」와 「오늘 기분 단어」를 나란히 적기.

**나쁜 예**  
- 「쌍둥이자리 청록색을 보면 불안이 치유됩니다.」  
- 「화성 붉은빛은 당신의 분노를 나타냅니다.」

## 3. 학술 앵커 (인용 우선순위)

| Tier | 출처 | 쓰는 때 |
|------|------|---------|
| **A** | Jonauskaite & Mohr 2025 | 색–감정 **연상**의 일관성·한계, 「연상 ≠ 체감」 |
| **A** | Elliot 2015 (Color-in-Context) | 맥락·문화·과제에 따라 의미 변동 |
| **A** | Jonauskaite et al. 2020 | 보편 패턴 + 문화·언어 차이 |
| **B** | NASA 별·행성 색 | 스펙트럼·표면온도·겉보기 색 사실 |
| **B** | Cajochen 2005 등 | 조명·명도·생리 (과장 금지, 환경 맥락만) |
| **C** | Heller 등 문화 사전 | **연상 후보** 참고만 — 치료·단정 근거 금지 |

`sources[]`에는 Tier A·B URL/DOI를 1건 이상 넣습니다. Tier C만으로는 `sources`를 채우지 않습니다.

## 4. 금지 표현 · 대체 표현

### 4.1 절대 금지

- Lüscher 색씨, 색채 치료 검사, 「스트레스 색」 진단
- 「이 색이 ○○ 감정을 **치유**한다」
- 「이 색을 보면 **반드시** ○○해진다」
- 출생 차트·운세·운명·팔자 + 색 조합
- 성격·유형 **확정** (「당신은 붉은 사람」)
- 임상·공식 검사 대체 암시

### 4.2 조심해서 쓸 것 (맥락 필수)

| 피할 표현 | 권장 대체 |
|-----------|-----------|
| 색이 마음을 바꾼다 | 색이 **연상을 떠올리게 할 수 있다** |
| ○○색 = ○○ 성격 | ○○ hue는 **탐구·기록용 앵커** |
| 치유·처방 | **10초 실습**, **시각적 앵커**, **그날의 기록** |
| 진짜 별의 색 | **겉보기 색**, **천문 사실**, **상징 hue** |
| 당신의 행성 색 | **1순위 울림**, **거울**, **단정이 아님** |

### 4.3 권장 어휘

- 떠올리기 쉬움 · 연상 · 맥락 · 명도·채도  
- 그날의 기록 · 탐구 질문 · 시각적 앵커  
- 천문 사실과 해석 분리 · 울림 · 거울  
- 연상 ≠ 체감 · Color-in-Context

## 5. 콘텐츠 타입별 필드 가이드

### 5.1 별자리 `data/signs.json` (4층)

| 필드 | 길이·내용 |
|------|-----------|
| `astronomyFacts[]` | 2~3문장. IAU·관측·별 이름. 운세 구간과 혼동 금지 문구 1회 권장 |
| `lightNote` | hex + **왜 이 hue인지**(원소·신화·가독성) + 천문색과의 관계(일치/불일치 명시) |
| `colorAssociation` | 「~을 연상시킬 **수 있다**」. 연구 요약 1줄 optional |
| `colorContext` | 명도·채도·맥락 + **면책 1문장 이상** (연상 ≠ 체감) |
| `colorPractice` | 10~30초, 실행 가능, 천문/연상 분리 연습 권장 |
| `sources[]` | DOI 또는 NASA 1건+ |

레거시 `colorPsych`만 있는 항목: 신규 필드 추가 시 `colorPsych`는 비우거나 요약만 유지. `sign.html`은 신규 필드 우선.

### 5.2 행성 `data/planet-types.json`

| 필드 | 내용 |
|------|------|
| `astronomy` | 궤도·구성 한 줄 (심리 없음) |
| `skyColorLabel` | 「겉보기: …」 짧은 라벨 |
| `skyColorFact` | 물리·대기·표면 성분 기반 1~2문장 |
| `hueNote` | 카드 hex = 아키타입 상징, 점술 아님 |
| `gift` / `shadow` | 심리 거울. **단정형 이름 붙이지 않음** |

### 5.3 `data/color-atlas.json`

- `disclaimer`·`globalNotes` 유지·갱신
- `astronomyBridge`: 천문색 vs 상징 hue **불일치를 버그가 아니라 층위**로 설명
- hex 변경 시 `signs.json` `color`와 동기화

### 5.4 연구 노트 `data/research-notes/*.json`

- `lead`: 학술 톤 + 사이트 방침 1문장
- `sections[]`: facts / interpretation 분리
- `practice`: 10초, 사용자 주도 기록
- `related[]`: 아틀라스·sign·sky 등 내부 링크
- `index.json`에 메타 등록 필수

### 5.5 인포그래픽 `infographic-details.json` → `light[]`

- 인포 palette hex = **디자인·가독성** 명시
- 「감정의 밝기」 등 **은유**는 `mirror`와 구분
- 천문 `facts[]`와 `light[]` 문장 혼합 금지

## 6. 집필 템플릿

### 6.1 `lightNote` (별자리)

```
{이름Ko}의 {hex}는 사이트에서 「{원소·테마}」의 상징색입니다.
천문학적으로 {별/현상}은 {겉보기 색 사실}이며,
{일치/불일치}하는 지점은 {한 줄 설명}입니다.
```

### 6.2 `colorPractice` (공통)

```
{대상 swatch/하늘/인포}를 10초 바라본 뒤,
「{연상 단어}」와 「{오늘 체감 단어}」를 각각 적어 보세요.
{천문/연상/체감}을 분리하는 연습입니다.
```

### 6.3 `skyColorFact` (행성)

```
{겉보기 색 라벨}은 {물리·화학·대기 메커니즘} 때문입니다.
{NASA/ESA 등 관측}에서도 {한 줄 사실}.
```

## 7. 검수 체크리스트 (1건 완료 시)

**집필자 자가 점검**

- [ ] 천문·디자인·거울이 다른 문단/필드에 있는가
- [ ] 「치유·운세·확정·반드시」 금지어 없는가
- [ ] `colorContext` 또는 동등 면책(연상 ≠ 체감) 있는가
- [ ] `colorPractice` 10~30초로 실행 가능한가
- [ ] `sources` Tier A 또는 B 1건 이상인가

**검수자 (Coco/Rostar)**

- [ ] 천문 사실 — NASA/IAU 대조 (웹 1회)
- [ ] hex — `color-atlas.json`·`signs.json` 일치
- [ ] 모바일 320px — `sign.html` / 인포 카드 줄바꿈
- [ ] 퀴즈·탐구 일지 문구와 톤 일치
- [ ] `research-bibliography.json` `avoid` 목록 위반 없음

## 9. 빠른 참조 (카피 붙여넣기용 면책)

> 색을 본다고 감정이 자동으로 바뀌는 것은 아닙니다. 별빛연구소는 색을 연상과 주의를 돌리는 시각적 앵커로 쓰며, 치료·운세 효과를 단정하지 않습니다.

> hex는 UI·탐구 앵커용입니다. 별·행성의 실측 겉보기 색·문화 상징과 1:1 대응하지 않을 수 있습니다.

> 결과는 그날의 자기 기록이며, 성격·운명의 고정값이 아닙니다.
